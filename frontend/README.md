# Frontend Triage Hospitalario

Este es el frontend del sistema de triage hospitalario, desarrollado con Streamlit.

## Instalación

1. Instala las dependencias:
   ```bash
   pip install -r requirements.txt
   ```

2. Asegúrate de que el backend esté corriendo en http://127.0.0.1:8000

3. Ejecuta la aplicación:
   ```bash
   streamlit run streamlit_app.py
   ```

## Características

- Interfaz intuitiva para admitir pacientes
- Visualización de lista de pacientes
- Obtención del siguiente paciente por prioridad
- Asignación de camas
- Diseño profesional y fácil de usar
